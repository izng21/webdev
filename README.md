## 📖 Overview

**BytePlay** is a web development final project featuring 12 standalone mini-games — all running directly in the browser with no frameworks, no npm, and no build step. Each game lives in its own folder and is fully self-contained. The home page (`index.html`) serves as a card-based game launcher.

> 🎓 Final project for **Web Development** — by Bruce Almaden, 2025.

---

## 🕹️ Games

| | Game | Folder | Description |
|---|---|---|---|
| 🧠 | **Memory Match** | `memorygame/` | Flip cards and find matching pairs |
| 🤓 | **Math Quiz** | `mathquiz/` | Solve arithmetic questions against the clock |
| 💪 | **Rock Paper Scissors** | `rockpaper/` | Classic hand game against the computer |
| ⭕ | **Tic Tac Toe** | `tictactoe/` | Two-player strategy on a 3×3 grid |
| ⌨️ | **SpeedType** | `typetest/` | Typing speed and accuracy test |
| 🎯 | **Number Guess** | `guess/` | Guess the hidden number with hints |
| 🧩 | **General Knowledge Quiz** | `gquiz/` | Multiple-choice trivia across categories |
| 🐹 | **Whack-a-Mole** | `mole/` | Tap moles before they disappear |
| 🪓 | **Hangman** | `hangman/` | Guess the word one letter at a time |
| 🍎 | **Catch the Falling Emoji** | `catch/` | Dodge bad items and catch the good ones |
| 💣 | **Mini Minesweeper** | `minesweeper/` | Reveal safe tiles and avoid the mines |
| 🐍 | **Snake Game** | `snake/` | Grow your snake without hitting the walls |

## 🛠️ Tech Stack

| Technology | Role |
|---|---|
| **HTML5** | Game structure, game launcher home page |
| **CSS3** | Card grid layout, game UI, animations |
| **Vanilla JavaScript** | All game logic, input handling, scoring |
| **Vercel** | Hosting & deployment |

> No npm. No framework. No build step — just open and play.

## 🚀 Getting Started

```bash
# Clone the repository
```

## 📁 Project Structure

```
webdev/
│
├── index.html              # 🎮  Game launcher (BytePlay home page)
├── homestyle.css           # 🎨  Home page styles & card grid
├── images/                 # 🖼️  Shared assets (favicon, etc.)
│
├── memorygame/             # 🧠  Memory Match
├── mathquiz/               # 🤓  Math Quiz
├── rockpaper/              # 💪  Rock Paper Scissors
├── tictactoe/              # ⭕  Tic Tac Toe
├── typetest/               # ⌨️  SpeedType
├── guess/                  # 🎯  Number Guess
├── gquiz/                  # 🧩  General Knowledge Quiz
├── mole/                   # 🐹  Whack-a-Mole
├── hangman/                # 🪓  Hangman
├── catch/                  # 🍎  Catch the Falling Emoji
├── minesweeper/            # 💣  Mini Minesweeper
└── snake/                  # 🐍  Snake Game
```

Each game folder contains its own `HTML`, `CSS`, and `JS` files — fully self-contained and independently playable.

## 🤝 Contributing

Got ideas for a new game or want to improve an existing one?

1. Fork the repository
2. Create a new folder for your game (e.g. `newgame/`)
3. Build it with self-contained HTML/CSS/JS
4. Link it as a new card in `index.html`
5. Open a Pull Request
